## Durability sweep (Measure)

Command: `erasure-coded-object-store bench -objects 20 -size 1048576 -seed 1` (in-process,
in-memory disks, no network). Image: `docs/proof/durability.jpg`.

**6 disks in 3 domains (2 each), k=4 m=2, 20 objects of 1 MiB**

| Disks lost | Combinations | Reads | OK | Unavailable | Wrong bytes |
|---|---|---|---|---|---|
| 0 | 1 | 20 | 20 | 0 | 0 |
| 1 | 6 | 120 | 120 | 0 | 0 |
| 2 | 15 | 300 | 300 | 0 | 0 |
| 3 | 20 | 400 | 0 | 400 | 0 |

Each whole domain lost (z1, z2, z3): 20 of 20 objects read. Wiping 2 disks and running `Repair`
on every object rewrote 40 shards in 134 ms; afterwards every object read with two other disks
down. Storage: 31,489,080 bytes for 20,971,520 object bytes = **1.502x** (code 1.500x plus the
shard headers), against 3.000x for three-way replication with the same two-disk tolerance.

**9 disks in 3 domains (3 each), k=6 m=3, 10 objects of 1 MiB**
(`bench -k 6 -m 3 -disks 9 -domains 3 -objects 10 -size 1048576 -seed 1`)

| Disks lost | Combinations | Reads | OK | Unavailable | Wrong bytes |
|---|---|---|---|---|---|
| 0 | 1 | 10 | 10 | 0 | 0 |
| 1 | 9 | 90 | 90 | 0 | 0 |
| 2 | 36 | 360 | 360 | 0 | 0 |
| 3 | 84 | 840 | 840 | 0 | 0 |
| 4 | 126 | 1260 | 0 | 1260 | 0 |

Each whole domain lost: 10 of 10 read. Storage 1.502x. Rebuild of 3 wiped disks: 30 shards in 94 ms.

No read ever returned wrong bytes: with more than m disks lost the store refuses
(`ErrUnavailable`) instead of guessing.

## Codec throughput

Command: `go test -run '^$' -bench . -benchtime 20x ./internal/rs` (1 MiB object, one core).

| Benchmark | Result |
|---|---|
| Encode 4+2 | 654 MB/s |
| Encode 10+4 | 283 MB/s |
| Reconstruct 4+2, two data shards lost | 593 MB/s |

These are table-lookup speeds without SIMD (ADR 0002). Bench end-to-end figures from the same
session: put 299 MiB/s, get 496 MiB/s at k=4 m=2 (in-memory disks).

## Analyze and Improve

Defects found while building M1, each with the test that now holds it:

| Defect | Root cause | Fix | Test |
|---|---|---|---|
| `Read` and `Delete` accepted an empty version name | the name check skipped validation when the version was empty (meant only for listing) | separate object-only check for listing | `TestInvalidNamesNeverTouchStorage` |
| A read could fail while another writer overwrote the key | the read listed version V, the writer committed V+1 and deleted V before the read fetched it | reads start over when the chosen version vanished (at most 5 attempts, with backoff) | `TestConcurrentPutsAndGets` (first failed, then failed again under load with 3 attempts) |
